Калькулятор академічного потенціалу

Вебсторінка, яка за 15 коротких тверджень показує, наскільки профіль людини схожий на профілі сильних учнів України за даними міжнародного дослідження **PISA 2022**.

> Це студентський навчальний проєкт. Він не є офіційним калькулятором KSE і не впливає на рішення грантової комісії. Результат — орієнтир для самоаналізу, а не прогноз.

---

## Проблема і рішення

**Проблема.** Вступники мають нерівний доступ до інформації про те, які навички й підходи до навчання пов'язані з сильними академічними результатами. Часто вони оцінюють себе лише за балом НМТ.

**Рішення.** Безкоштовний інструмент самоаналізу: 15 запитань, результат одразу в браузері, без реєстрації й без збору даних. Профіль відповідей порівнюється з профілями учнів, які мали найвищі бали в PISA.

## Що вміє калькулятор

1. **Вибір гранту:** академічний, Come back home або фінансова допомога. Для кожного показано спрощену перевірку умов.
2. **15 тверджень у 8 групах** зі шкалою від 1 до 5. Під кнопками підписано, що означають крайні значення. Правильних відповідей немає.
3. **Результат:**
   - рівень потенціалу з п'яти (від «дуже низького» до «високого»);
   - перцентиль серед українських учнів PISA 2022;
   - частка учнів цього рівня, які потрапили в топ-25 % за балом PISA.

## Як це працює

PISA — дослідження OECD, у якому 15-річні учні пишуть тест (математика, читання, природничі науки) і заповнюють анкету про себе й навчання. Тому для кожного учня відомі і **бал**, і **відповіді на анкету**.

1. Ми визначили, які відповіді на анкету найкраще відрізняють учнів із найвищим сумарним балом (топ-25 %).
2. З них відібрали 15 тверджень, на які заявник може чесно відповісти сам.
3. Кожну відповідь переводимо в відхилення від середньої відповіді українських учнів, усереднюємо в межах групи й складаємо групи за вагами.
4. Підсумок ставимо серед підсумків учнів PISA, так отримуємо перцентиль і один із п'яти рівнів по 20 % учнів.

### Групи тверджень і ваги

| Група | Вага |
| --- | --- |
| Впевненість у математиці | 28 % |
| Різні точки зору | 17 % |
| Віра в розвиток здібностей | 16 % |
| Критичне мислення з інформацією | 16 % |
| Допитливість | 13 % |
| Додаткові зусилля | 4 % |
| Складні завдання | 3 % |
| Розв'язання проблем | 3 % |

### Перевірка

Запитання й ваги добирали на одній половині шкіл бази PISA, а перевіряли на іншій половині. Показник AUC калькулятора — **0,74–0,78**.

## Дані

- **Джерело:** OECD, PISA 2022, база учнівського опитування, Україна.
- **Вибірка:** 3 876 учнів із 18 із 27 регіонів.
- **«Сильний учень»:** топ-25 % за середнім балом з математики, читання й природничих наук.
- **Розрахунки:** зважені офіційною вагою учня; довірчі інтервали бутстрепом по школах; пропущені відповіді відновлено множинною імпутацією (5 наборів).
- Текст тверджень перекладено й скорочено командою; коди змінних PISA збережено в коді сторінки (наприклад, `ST290Q09WA`) для пошуку в кодовій книзі OECD.
